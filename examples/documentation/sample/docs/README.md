# Docs map

What is here and where to start. Start with [`STATUS.md`](./STATUS.md), then pick an item from the
[open backlog](./backlog.md).

| Path | What it is |
|---|---|
| [`STATUS.md`](./STATUS.md) | One page: what is deployed, what runs, what is next, what waits for the owner. |
| [`decisions.md`](./decisions.md) | The current decisions, one line each with the item that carries the reasoning. |
| [`backlog.md`](./backlog.md) | Generated index of the open items. |
| [`backlog-done.md`](./backlog-done.md) | Generated index of the finished items. |
| [`backlog/`](./backlog/) | One file per item; finished ones in `done/`. |
| [`checks.md`](./checks.md) | Generated: every check and what it enforces. |
